## Запуск

Нужны Docker и Docker Compose.

```bash
cd exchange-crypto
docker compose up --build
```

## Примечания

Compose использует API на порту 8080 и сервер БД на 7432. Каталог PR34SR3 содержит другой вариант той же практической.
